# Hybrid-Edited-Learning

MATLAB implementation of a **hybrid-system-based neural network editing framework** for physics-compatible dynamics learning. This repository contains the complete simulation code behind the paper:

> **"A Hybrid-System-Based Neural Network Editing Framework for Physics-Compatible Dynamics Learning"** (under review, *Journal of the Franklin Institute*).

The framework combines a **Maximum-Entropy distributed hybrid architecture** with a **physics-guided editing mechanism** built on **Physics Information Matrices (PIM)** and **Temporal Knowledge Matrices (TKM)**, producing lightweight, verifiable surrogate models for chaotic dynamics, closed-loop control, and real-time model-predictive control.

## What the code does

A Physics-compatible Neural Network (PhNN) uses a Taylor monomial library as its feature map and a structured weight matrix:

```
W_eff = A_value + A_uncertain ⊙ W_learn
```

- **PIM** encodes the known physical structure of the dynamics: known-zero connections are pruned (`A_uncertain = 0`), known coefficient values are fixed (`A_value ≠ 0`, e.g. the Euler self-coefficient `1 − dt`), and only physically relevant monomials remain learnable.
- **TKM** extends the same idea to temporal (lagged) inputs by pruning monomials that mix different time steps.
- The **hybrid architecture** performs PCA on the state, then a Maximum-Entropy bisecting partition that splits the state space into N sub-regions, each served by a small local PhNN trained in parallel. This decouples approximation accuracy from model complexity.

Two families of experiments reproduce the paper's results:

1. **Lorenz-96 chaotic dynamics** (Section 4.1) — four editing configurations (unedited / PIM / TKM / PIM+TKM), SINDy sparse-regression comparison on the *same* Taylor library and data, and the PCA+ME hybrid scaling study.
2. **Coupled oscillator network with certainty-equivalence LQR control** (Sections 4.2 / 5) — dynamics learning plus closed-loop regulation, including a single-model vs. hybrid comparison.
3. **Vehicle dynamics and MPC path tracking** (Section 5.2) — `code/mpc/mpc_improved.m` applies the PhNN surrogate to a model-predictive control task.

## Requirements

- **MATLAB** (R2021b or later recommended). No additional toolboxes are required — the PCA step and the SINDy comparisons are implemented with base MATLAB functions.
- **Python 3** with `numpy` and `matplotlib` is optional and only used by `code/tools/plot_matlab_style.py` for re-styling figures.

## Quick start

```matlab
cd /path/to/Hybrid-Edited-Learning
startup            % cd to repo root, add code/ and misc/ to the path
lorenz96_experiment   % Section 4.1: Lorenz-96 editing experiment (~5 min)
```

See [docs/QUICKSTART.md](docs/QUICKSTART.md) for the full, per-experiment run order with expected outputs.

## Reproduction notes

- **Section 5.1 (AutoRally vehicle dynamics)** uses external data and the identification pipeline of the cited work (`mao2022phy`); no local data or code is included for that subsection. The PhNN/MPC code that consumes such a surrogate is in `code/mpc/`.
- Measured runtimes (reference machine): `lorenz96_experiment` ≈ 326 s, `oscillator_control` ≈ 94 s (see `results/simulation_run_log.txt`).
- All experiment scripts write their outputs to the repo-root `results/` and `fig/` folders, regardless of where they are invoked from. Run `startup` first so the scripts resolve each other via the MATLAB path.
- `legacy/` contains an earlier procedural implementation with a different API (`phnn_train`/`phnn_forward`); it is kept only for reference.
